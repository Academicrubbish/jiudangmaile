# 就当买了

假装花一笔，把钱留给自己。项目采用 **uni-app Vue 3 + uniCloud 阿里云云函数／云数据库**。

GitHub：https://github.com/Academicrubbish/jiudangmaile

## 当前已编码

- 奔驰与烟钱的开场梗、每日自动事件预算、多选／自定义习惯及每次金额范围设置、纸张与荧光绿的单事件首页。
- 首页常驻主动花钱、请客、消费记录和消息提醒入口；自动事件预算与主动消费分离，随机小事以未读卡片呈现。
- 个人虚构消费、跳过、精神小票、自行转存提示、实际金额确认和撤销。
- 默认昵称与可选图形头像、单人请客邀请、24 小时有效期、好友接受。
- 双方查看同一事件、首次接受来源、事件时间线和已加载物品汇总。
- 云端身份校验、金额规则、私有数据隔离、重复操作保护和事务冲突重试。
- GLM-5.2 场景生成、独立语义复核、提前十五分钟准备随机事件、订阅次数累计、记住允许后的操作补充、暂停与发送状态管理。

实际业务数据由云函数 `jdml-api` 读写云数据库，客户端没有直写权限。微信登录沿用模板内的 `uni-id-co` 与 `uni-id-common`。

## 当前阶段的边界

当前为 0.2.0 编码版本，已接入智谱 GLM-5.2、独立内容复核、预审兜底、随机定时任务和微信订阅提醒代码。你提供的 Key 保存在 Git 忽略的本地配置。已按用户要求单独调用智谱验证抽象风格候选样例，尚未做云端部署或真机业务联调；微信提醒已接入获准模板 1646，本地私密配置已启用，须更新云函数并验证微信授权与凭据后测试实际触达。详见 [AI 与随机提醒接入](docs/AI与随机提醒接入.md)。自定义上传头像、图片版分享海报、注销与反馈入口、全量物品聚合也待后续迭代。

支付功能不在本期：小票不是支付凭证，复制金额和返回应用不会自动记为转存；只有本人明确确认才增加记录。收到朋友请客不会增加自己的转存金额。

## 代码结构

- `pages/`：七个业务页面。
- `components/jdml/`：品牌导航和抽象物品插画。
- `services/api.js`：平台登录、云函数调用、重试操作编号与金额显示。
- `uniCloud-aliyun/cloudfunctions/jdml-api/`：客户端业务入口与账号校验。
- `uniCloud-aliyun/cloudfunctions/common/jdml-core/`：共享业务规则、AI、定时计划、提醒与云数据库适配。
- `uniCloud-aliyun/cloudfunctions/jdml-worker/`：定时任务入口。
- `uniCloud-aliyun/database/jdml-*`：业务集合与索引。
- `uni_modules/`：原模板提供的 DCloud 组件与账号模块。
- `tests/`：业务规则和云数据库事务接口检查。
- `.project-backup/initial/`：初始模板及本次替换文件的本地备份，Git 忽略。

代码检查：`npm test` 与 `npm run check`，均不启动应用，不连接真实云数据库。安装开发依赖后，可用 `npm run build:weixin`／`npm run build:h5` 进行纯编译；这些命令也不启动应用。编译检查单独记录在 [代码检查结果](docs/代码检查结果.md)。


剧情口味已加入习惯设置：贴近习惯（80/20）、各来一半（50/50，默认）、多点意外（20/80）。比例仅影响自动事件，跨天累计；主动花钱和请客可从独立商品库任选，或临时填写商品与本次金额，不改变人设。生活小插曲从普通生活商品中选题，AI 创作荒诞但贴近日常的购买理由。
